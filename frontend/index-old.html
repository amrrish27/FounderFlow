HOW TO READ THIS PAGE
1. Enter startup signals The current model expects 15 numeric values from the training dataset. Some fields are dataset codes rather than human-readable names.
2. Run the model FounderFlow sends the values to the FastAPI production endpoint and the Random Forest classifier.
3. Read the result Exited means the model predicts an exit class. Not Exited means it predicts the non-exit class. This is a probability estimate, not a guarantee.
Important: This version keeps the existing 15-feature production model unchanged. Therefore fields such as Country Code, Industry Code, Tags Code and Exit Type Code are required in the same numeric format used by that model.

RESULT GUIDE

What does the prediction mean?

FounderFlow reports two probabilities. A higher Exited probability means the model sees the startup as more similar to historical records in the exited class. A higher Not Exited probability means the opposite.

These numbers describe model confidence for the supplied data; they are not a guarantee of a future acquisition or IPO.
